# SophiMotion 铭牌工作台

所有编辑、草稿和二维码均在浏览器本地处理。Three.js 负责外观预览，SVG 排版负责生产导出。

## 运行

```powershell
npm install --cache .npm-cache
npm run build
python -m http.server 4173 --directory dist
```

打开 http://localhost:4173 。打印选择实际大小 / 100%，关闭页眉页脚。PDF 通过系统打印对话框保存。SVG 文字保留为文本，送厂前应确认字体兼容，必要时在矢量软件转曲。PNG 写入 300 DPI 元数据。

## 使用

- 基础信息中修改字段，点击 × 删除；拖动左侧手柄排序，也可聚焦手柄后按上下方向键。
- 尺寸样式中设置毫米尺寸、字号、边距、安装孔和材质。
- 二维码默认编码当前标题及全部字段，可切换自定义文本或网址。
- 排版错误时生产导出被禁用，按提示调整后恢复。
- 配置 JSON 可备份和导入，浏览器草稿自动保存。清空浏览器数据会清除草稿。

三维预览需要 WebGL，不可用时自动切换二维模式。实际打印缩放受打印驱动影响，请先用尺测量样张并扫码验证。
