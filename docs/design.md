# SophiMotion 铭牌工作台

用户已确认：可增删排序的基础字段，Three.js 金属铭牌预览，正面生产稿，毫米尺寸、自动排版、二维码、SVG/PNG 导出与实际尺寸打印、本地草稿及 JSON 导入导出。

实现为浏览器本地应用，不上传铭牌数据。SVG 是排版唯一来源，预览纹理、PNG、打印均由相同 SVG 派生；Three.js 仅展示材质，不参与生产导出。二维码保留四模块白边，深色模块始终黑色。过密、超长或空间不足时阻止生产导出并说明原因。

文件：dist/index.html 为界面；dist/style.css 为响应式品牌样式；src/layout.js 为纯排版和序列化；src/preview.js 为 Three.js；src/app.js 为状态及交互。esbuild 打包依赖到本地，避免运行时 CDN。

执行顺序：1. 排版及边界测试；2. 字段表单及二维码；3. 三维预览及导出；4. 浏览器检查桌面、手机、打印、草稿和文件导入；5. 打包发布。

验收：二维/三维共享文本，删除及排序立即生效；XML 特殊字符安全；中文/长地址自动换行；拥挤提示且禁止导出；PNG 300 DPI 对应像素；SVG 使用 mm；二维码解码等于原文；打印只输出平面稿。
